# Acorn Forest: Merge! — Godot project

**Acorn Forest: Merge!** is a cozy *merge-to-grow* game: a child crosses into a fading
spirit-forest and tends one persistent merge board. Drag any two matching items together
to merge them up a tier ladder, deliver harvests to the grove's spirit-folk for Stars,
and restore a hand-painted "Ghibli Grove" homestead.

The canonical design — spec **and** feature index — lives in
[`docs/design/merge_spec.md`](docs/design/merge_spec.md). (Early prototype specs and the pivot history are kept under
[`docs/archive/`](docs/archive/).)

## Requirements
Godot **4.6** (developed on 4.6.2). On this machine: `/opt/homebrew/bin/godot`.

## Run the game
- **Editor:** open this folder as a Godot project and press Play.
- **CLI (desktop):** `godot --path .` — opens a portrait window; mouse-click acts as touch.
- Main scene: `engine/scenes/Boot.tscn` (authoritative: `run/main_scene` in `project.godot`).

## Run the tests (headless — no display needed)
Suites run **in parallel** with a per-suite timing table (`engine/tools/run_suites.py`,
`JOBS=4` by default). After **every change**, run the fast inner-loop check; run the
full sweep only before you commit or hand off:
```bash
make test-fast      # ⚡ INNER LOOP — engine suites only, parallel (use after every change)
make test           # full sweep: every suite (engine + grove), parallel + timing table
make test-engine    # base-engine suites only
make test-grove     # grove game suites only
make test-one SUITE=engine/tests/save_tests   # a single suite (serial)
make test-config    # the non-godot python/bash guards only (also a prerequisite of `make test`)
make smoke          # scene-instantiation smoke check
JOBS=8 make test    # raise/lower parallelism
```
Suites live beside the code they cover: the base-engine ones in `engine/tests/`, and the
grove game's in `games/grove/tests/`. The grove suite was split from one 2.3k-line
monolith into focused suites sharing `grove_test_base.gd`, so they parallelise and you
can run just the slice you touched. The authoritative list is `GROVE_TESTS` in the
`Makefile`: `grove_board_actions_tests`, `grove_explore_tests`, `grove_scene_workbench_tests`, `grove_scene_covers_tests`, `grove_shop_tests`, `grove_ui_workbench_tests`, `grove_ftue_tests`, `grove_rush_ftue_tests`, `grove_cascade_tests`.
`engine/tests/suite_registry_tests.gd` fails if that list, this line and `CLAUDE.md` name
different sets (membership, not order), and if any `*_tests.gd` / `test_*.py` / `test_*.sh`
on disk is missing from the Makefile — a suite nothing runs looks exactly like a passing one.

## Layout
| Path | Role |
|---|---|
| `engine/scripts/` | Shared engine code, split by dependency: `core/` is the pure, verified rules layer (no UI deps) — `board_logic.gd` + `board_model.gd` + `board_actions.gd`, plus save/quests/economy; `ui/` is widgets and the kit; `scenes/` holds the live scene scripts (`boot.gd`, `board.gd`, `map.gd`, `explore_rush.gd`). Note `scenes/board.gd` is the **scene** script, not the rules engine. |
| `engine/scenes/` | `Boot.tscn` (main scene), `Board.tscn`, `Map.tscn`, `ExploreRush.tscn`. |
| `games/grove/` | The game itself: content + tuning (`grove_data.gd`, `economy_tuning.json`, `strings.json`), its kit (`ui_kit.gd`), and `assets/` — source art & audio, hand-painted grove style. |
| `data/` | Shipped game data (`iap_products.json`, `level_badges.json`). Tests + dev tools live beside the code they serve: `engine/{tests,tools}`, `games/tools`, `games/<game>/{tests,tools}`. |
| `docs/` | Design specs, art pipeline, and planning. `docs/archive/` holds superseded history. |
| `tools/` | Repo-level build/release scripts (iOS export, version stamp, plugin install) and their non-Godot guards. |
| `build/` | iOS export output — **gitignored**, regenerated by `godot --export`. The one exception is `build/ios/ci_scripts/ci_post_clone.sh`, deliberately tracked for Xcode Cloud (`.gitignore` un-ignores it). |

## Mobile / iOS
Portrait (`display/window/handheld/orientation=1`) with the mobile renderer. iOS build &
sideload use the `export_presets.cfg` "iOS" preset; exports land in the
gitignored `build/ios/`.
