# Fairy Hollow Market v1

Layer-aware Scene Workbench bundle based on `fairy_hollow_layered_mushroom_market_paper_plate_mock_v2.png`.

This is a first-pass Workbench scene: the foundation is a generated empty-plate backdrop, while the six replaceable hero clusters are source-aligned crops that preserve the approved paper-plate look. After composition approval, replace each crop with a clean regenerated transparent sprite.

Open with:

```bash
make sw SCENE=fairy_hollow_market ROOT=res://games/grove/assets/_new/ui_redesign_direction_b/picturebook_scene_mocks_v1
```

Headless screenshot:

```bash
make shot-sw SCENE=fairy_hollow_market ROOT=res://games/grove/assets/_new/ui_redesign_direction_b/picturebook_scene_mocks_v1 OUT=/tmp/fairy_hollow_market_sw.png
```
