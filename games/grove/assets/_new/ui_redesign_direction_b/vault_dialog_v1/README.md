# Vault Dialog Mock v1

Generated high-fidelity UI mock for the redesigned Vault dialog.

Files:

- `vault_dialog_v1_source.png`: untouched generated source render.
- `vault_dialog_v1_1080x1920.png`: normalized review copy for phone mock comparison.
- `vault_dialog_v1.prompt.txt`: prompt used for the source render.

This mock follows the consolidated Meadow Sky + Cut-Paper Playground style. The old vault screenshot
was used as a content reference only; the layout was recreated around a larger filled jar, a clear
premium-value tray, a single claim button, and a short fill-progress note.
