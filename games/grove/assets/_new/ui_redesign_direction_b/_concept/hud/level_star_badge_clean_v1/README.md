# Clean Level Star Badge

Reusable blank base for the upper-left level badge, rebuilt from the supplied reference.

- `level_star_badge_base_512.png` — primary transparent PNG.
- `level_star_badge_base_256.png` — HUD-ready transparent PNG.
- `level_star_badge_base_master.png` — full-resolution transparent master (1254 x 1254).
- `level_star_badge_source_magenta.png` — chroma-key generation source retained for provenance.

The `2` is intentionally omitted: render the current level number as UI text over the gold star.
The asset has no external cast or contact shadow; the warm darker edge under the gold star is the
intentional paper-layer separation from the cream backing.
