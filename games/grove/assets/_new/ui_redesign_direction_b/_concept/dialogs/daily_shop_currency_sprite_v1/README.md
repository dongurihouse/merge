# Daily + Shop currency sprites

Reusable master UI sprites in the Meadow Sky / Cut-Paper Playground style. All source icons are 512 x 512 transparent masters, with no baked shadows; use the runtime's normal bake path for 256px UI glyphs.

## Daily rewards

- `coin_single_512.png` and `coin_stack_512.png`
- `water_droplet_512.png`
- `acorn_single_512.png` and `acorn_bundle_512.png`
- `mystery_gift_512.png`

## Shop

- `coin_pouch_512.png` and `acorn_coin_pouch_512.png` for purchasable currency packs
- `watering_can_512.png` for the refill card
- Single / stack variants for balance and price chips

`daily_shop_currency_sheet_1536.png` is the row-major 3 x 3 master sheet. The raw keyed generation, cleaned source, pipeline metadata, and prompt are retained for handoff. These are concept assets only and are not wired into the game yet.
