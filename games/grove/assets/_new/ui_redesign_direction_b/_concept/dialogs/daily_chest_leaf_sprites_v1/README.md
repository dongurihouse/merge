# Daily chest leaf-sprig sprites

Four transparent 512 x 512 masters for framing a daily-reward chest without fusing decoration into the chest asset.

- `chest_leaf_tall_left_512.png` / `chest_leaf_tall_right_512.png`: full-size daily chest or reward-card flanks.
- `chest_leaf_short_left_512.png` / `chest_leaf_short_right_512.png`: compact tile-corner flanks.

Place the left and right variants just outside the chest silhouette, with a little visual separation. They carry no baked shadow and do not overlap the chest artwork. The source sheet is `daily_chest_leaf_sprigs_sheet_1024.png`; alpha and containment QC is recorded in `manifest.json`.
