# Desert Oasis Watchtower — foundation checkpoint (v2)

This bundle contains three independently composable scene layers:

1. `01_backdrop` — stable sand, dunes, pond and stepping-stone route.
2. `03_structures` — five swappable transparent hero clusters: adobe compound, watchtower, market
   stall, travel tent and camel caravan. Each receives the workbench's runtime silhouette shadow.
3. `05_dressing` — lake-bank and foreground cover items that blend the structures into the terrain.

No hero asset bakes in a sand pad, grass island or painted ground shadow.
