# Desert Oasis — Watchtower Caravan Stop Scene Workbench, v1

This opens as `desert_oasis_watchtower` in Scene Workbench. It is intentionally a **planning
scene**, not a production reconstruction: the selected composite mock is a temporary base canvas
so that the recorded socket layout can be inspected before art generation begins.

The base will be replaced next with a foundation containing only fixed terrain. The five future
hero clusters and fixed cover-dressing zones are specified in the sibling layer plan:

`../desert_oasis_watchtower_layer_plan_v1/metadata/source_bounds.json`

Open it with:

```bash
make sw SCENE=desert_oasis_watchtower ROOT=games/grove/assets/_concepts/zones
```
