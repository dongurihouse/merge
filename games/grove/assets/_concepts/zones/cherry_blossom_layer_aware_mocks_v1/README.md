# Cherry Blossom Layer-Aware Mocks v1

Three dressed reference concepts for selecting a production composition before generating the registered backdrop, four replaceable hero groups, and fixed covering layer.

Primary reference: `../cherry_blossom_garden_temple_concept_v1.png`

Secondary style reference: `../cherry_blossom_garden_original_mock_v1.png`

Hero groups in every mock:

1. pavilion;
2. temizuya with basin, bamboo spout, water, and ladles;
3. torii gate;
4. pond precinct with koi, lily pads, and bridge.

The prompts intentionally forbid extra landmarks and scattered micro-props. These are flattened reference mocks only; approved production layers will be generated separately.
