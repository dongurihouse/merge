# Cherry Blossom Paper-Plate Terrace — Scene Workbench v1

This bundle reconstructs the approved paper-plate mock as a modular Scene Workbench scene.

- Stable family: peach sky, mountains/zen sand/stepping path, two clouds.
- Replaceable clusters: pavilion plate, pond plus bridge plate, temizuya plate, torii plate.
- Fixed cover: cropped cherry trees, edge bushes, flowers, rocks, and sparse petals.

Every replaceable cluster owns its local paper base, plate rim, contact shadow, and touching companion dressing. The source mock remains a composition reference; its pixels are not extracted into runtime assets.
