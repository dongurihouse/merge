# Desert Oasis — Watchtower Caravan Stop layer plan, v1

The selected reference is a **layout reference**, not a source image to deconstruct. The scene
will be built as three layers, using these recorded sockets as the composition authority.

1. **Foundation:** fixed sand, terrain texture, stepping-stone path, pond/water/shoreline, and
   distant dunes/mountains. Sky and clouds remain an independent atmosphere layer behind it.
2. **Hero objects:** five independently replaceable clusters positioned at the recorded sockets.
3. **Cover dressing:** fixed trees, vegetation, rocks, and flowers at the perimeter and socket
   seams; it paints above hero objects to hide joins without becoming part of any one object.

The first production-art checkpoint is foundation-only, generated from this contract rather than
from an object-removal edit of the reference mock.
