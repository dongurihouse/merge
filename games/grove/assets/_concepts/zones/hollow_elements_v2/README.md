# Fairy Hollow Market — element bundle v2

`fairy_hollow_market_v2` separates a continuous forest foundation from six movable hero clusters.
Every hero sprite includes its own tan cut-paper plate, local foliage, rocks, and flowers. The
foundation deliberately contains no empty plate or socket, so removing or moving a cluster leaves
ordinary forest ground rather than a baked placeholder.

Open in Scene Workbench:

```bash
make sw SCENE=fairy_hollow_market ROOT=res://games/grove/assets/_concepts/zones
```
