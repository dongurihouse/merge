# Winter layered mock variations v1

These are intentionally sparse, composed references for the new scene-production process. They are not
assets to deconstruct automatically. Each mock is built around one stable ordering:

1. `sky_atmosphere` — separate painted pass, behind the world.
2. `backdrop` — terrain, paths, water, distant mountains, perimeter vegetation; no hero props.
3. `hero_objects` — exactly five named, separated replacement candidates with visible ground footprints.
4. `coverings` — fixed foreground spruce, bush, rock, and snow-bank groups that mask seams but never
   substantially obscure an object.

The mock prompt is deliberately restricted to large, isolated silhouettes. It forbids loose micro-props
so a future scene can be generated as a few robust object assets instead of reconstructed from dozens of
unreliable extractions.

| Mock | Hero object contract |
| --- | --- |
| `winter_layered_lantern_lodge_plaza_v1.png` | lodge, gazebo, stone bridge, dock+rowboat, entrance arch |
| `winter_layered_frozen_market_harbor_v1.png` | market hall, roofed fishing pier, sled shelter, footbridge, waterside gate |
| `winter_layered_snowcap_observatory_garden_v1.png` | observatory, viewing pavilion, pond bridge, wayfinding monolith, entrance gate |

All three are portrait 941×1672 reference mocks in the Meadow Sky + Cut-Paper Playground direction.
