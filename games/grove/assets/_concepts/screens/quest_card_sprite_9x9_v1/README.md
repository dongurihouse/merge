# Quest card sprite sheet — 9×9

`quest_cards_9x9_cutpaper_v1.png` is a raw 9-column × 9-row sheet (81 distinct quest-card concepts) on the project-standard `#FF00FF` key color. Every card includes a resident/creature portrait, requested-item bubble, and attached gold reward plaque.

The individual card art is generated; the final 9×9 arrangement is deterministic postprocessing from 80 generated card variants plus one distinct fox-librarian variant. The sheet is a concept/reference asset, not a runtime atlas contract.
