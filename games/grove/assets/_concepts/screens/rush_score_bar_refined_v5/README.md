# Rush — refined score-bar mock v5

This variation keeps the current Rush structure but improves glanceability during active play.

- `Score` is the central, enlarged reward-gold panel.
- `Time` is a compact left gauge with a small coral urgency tick.
- `Mult` is a compact right gauge with the acorn-crown medal.
- Treefall rail, all-open 7 x 9 board, danger column, and the persistent help strip are unchanged.

This is a visual concept only and is not wired into the game.
