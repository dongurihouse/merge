# Expedition Rush — tree-fall queue mock v3

The Rush action module is a live upcoming-event state rather than a line of peer actions.

- Hero action: `TREE FALL` with a large tree token.
- Event state: `COMING UP` and an explicit 3 / 5 green progress bar.
- Follow-on actions: a small flowerpot and acorn preview only, visually secondary.
- The score bar, timed merge board, and how-to-play strip remain unchanged from the board-play direction.

This is a visual concept only and is not wired into the game.
