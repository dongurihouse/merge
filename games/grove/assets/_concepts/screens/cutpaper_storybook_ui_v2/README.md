# Board HUD v2 — Layered Storybook

This is a review mock, not a runtime screen. It follows the established Cut-Paper Playground and Meadow Sky system while using the v1 Home mock as the UI-hierarchy reference.

Changes from Board v1:

- The unlock state is a short, mostly rectangular cream progress plaque with a clean green fill bar and no internal decorative icons.
- Every quest card carries its own attached gold reward plaque.
- The selected-item information bar spans the safe width and has item icon, name, information affordance, and a priced acorn action.

The image is stored at 1080 × 1920. `board_cutpaper_storybook_ui_v2.prompt.txt` records the source generation contract.
