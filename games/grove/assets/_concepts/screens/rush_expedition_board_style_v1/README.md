# Expedition Rush — board-style mock

The first Rush / Expedition page in the current Meadow Sky + Cut-Paper Playground UI direction.

- Shared global level and resource rail from the Board screen.
- Stage progress and timer directly under the title.
- A three-stop expedition trail: claimed chest, current leaf-framed reward chest, and a locked future chest.
- Reward summary and a single primary `START RUSH` action.
- Shared bottom navigation with Explore selected.

This is a visual concept only; it is not wired to the game.
