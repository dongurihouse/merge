# Expedition Rush — board-play mock v2

Rush is a timed board-play mode using the shared Meadow Sky + Cut-Paper Playground UI language.

- Top run card: score, remaining time, and active multiplier.
- `UP NEXT` tray: the current tree action followed by three queued actions.
- Central 7 x 6 merge board: the primary Rush interaction.
- Bottom information strip: one concise instruction and an info icon; no navigation competes with active play.

This is a visual concept only and is not wired into the game.
