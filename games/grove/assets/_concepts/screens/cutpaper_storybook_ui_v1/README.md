# Layered Storybook HUD Concepts

Two 1080 × 1920 visual concepts for the Grove Board and Home screens. They are art-direction references only and do not change the runtime UI.

## Shared system

Both mocks replace the earlier smooth, pill-heavy chrome with a **Layered Storybook HUD**: distinct die-cut paper silhouettes, warm cut edges, fine paper fibre, restrained down-right shadows, and overlapping navigation tabs. The common system is visible in the level rosette, three resource tags, selected navigation state, and cream utility surfaces.

## Files

- `board_cutpaper_storybook_ui_v1.png` — merge Board with a torn/scalloped unlock trail, request postcards, irregular slate paper board, folded selected-item flap, and selected Board tab.
- `home_cutpaper_storybook_ui_v1.png` — farm Home screen with compact edge utilities, a lower-right build/customization rosette, and selected Home tab.
- `*.prompt.txt` — exact source prompt recorded beside each output.

## Reference roles

- `docs/design/art-style-guide.md` is the style and palette source of truth.
- `palette_a_meadow_sky_board.png` supplied palette and paper-material authority.
- `home_screen_meadow_sky_v2_working_farm.png` supplied phone-scale and detail-budget authority.
- Existing Board/Home concepts supplied screen content hierarchy only.
- The detailed layered zone scenes supplied the richer paper-craft treatment; their layouts were not copied.

## Non-goals

These flat mocks are not sliced runtime assets, do not specify hit areas, and do not prescribe implementation geometry pixel-for-pixel. Keep the shared paper component grammar when translating them into production UI.
