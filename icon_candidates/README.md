# App icon candidates

Alternate cut-paper app icon concepts (1024x1024 opaque PNG), generated 2026-07-23.
The active game icon is `../icon.png` (the "oak tree" concept from this batch); the
iOS AppIcon set is filled from it at export time (the `export_presets.cfg` icon slots
are empty, so Godot scales the project icon).

To swap: copy a candidate over `../icon.png`, then regenerate
`build/ios/AcornForest/Images.xcassets/AppIcon.appiconset/Icon-*.png` (next iOS
export rewrites them automatically).
