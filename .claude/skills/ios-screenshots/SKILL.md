# iOS release screenshots

One command captures the whole release set into `appstore_screenshots/` and verifies every
file's pixel size:

```bash
games/grove/tools/release_screenshots.sh
```

Runs quietly (off-screen windows, never shown, never steals focus), takes ~2-3 minutes, and prints
`ALL SCREENSHOTS OK` on success. Run it from a worktree, review, then commit + merge — the
PNGs are repo files.

## What it produces

| file | view | size |
|---|---|---|
| `01_title_splash.png` | boot key art, loading bar hidden | 1284×2778 (iPhone 6.7") |
| `02_restored_world.png` | fully restored Fairy Hollow home | 1284×2778 |
| `03_merge_board.png` | played merge board (items · generators · quests) | 1284×2778 |
| `ipad/00_title_splash.png` | boot key art | 2048×2732 (iPad 12.9") |
| `ipad/01_homestead.png` | fully restored home | 2048×2732 |
| `ipad/02_merge_board.png` | played board | 2048×2732 |

The older extra slots (`04_…`–`07_…`, `ipad/03_…`–`05_…`) are NOT regenerated by the script;
capture those views manually with the same tools if they need a refresh.

## Review before shipping

Open each PNG and check: no debug text, no popup covering the view, locks/covers/shadows match
the current design, and the board shows lively state (items + generators, not an empty grid).
The capture is seeded and deterministic, but the game look changes — eyes on every refresh.

## How it stages each view (for one-off captures)

All three run through `engine/tools/quiet_godot.sh` (REQUIRED — a bare godot run flashes and
steals focus). `WxH` sets the capture size; any App Store size works.

```bash
# splash — boot.gd in capture mode; `noload` hides the progress bar
engine/tools/quiet_godot.sh --path . -s res://engine/tools/boot_splash_shot.gd -- out.png 1284x2778 noload

# home — map_shot `owned` unlocks every spot AND cluster → fully restored scene
engine/tools/quiet_godot.sh --path . -s res://games/grove/tools/map_shot.gd -- owned out.png 1284x2778 noftue=1

# board — grove_shot `played` merges + pops a seeded board
engine/tools/quiet_godot.sh --path . -s res://games/grove/tools/grove_shot.gd -- played out.png 1284x2778
```

Other useful map_shot/grove_shot modes for extra slots: `maps` (gallery), `bag`, `level`,
`ladder` — see each tool's header for the roster.

## Gotchas

- The shot tools use their own temp saves — they never touch the dev save.
- `map_shot owned` must seed CLUSTER ids as well as spot ids (fixed 2026-07-22); if a scene
  renders fully overgrown, that drift has returned.
- New PNGs inside the repo get `.import` files on the next editor/game run — commit those too.
